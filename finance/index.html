Make.com integracija — čekių importas

Make.com scenarijo struktūra: FB Messenger → OCR → Parse → HTTP POST
Žemiau — JSON formatas kurį siųsti į Google Apps Script endpoint.

POST body (JSON) — vienas čekis:
{ "companyId": "darts", "year": 2026, "month": 8, "date": "2026-08-10", "location": "Palanga", "cash": 101.50, "card": 419.19, "total": 520.69, "fiscalNr": "00011607" }
Make.com → Google Apps Script (doPost) kodo šablonas:
function doPost(e) { const d = JSON.parse(e.postData.contents); const ss = SpreadsheetApp.openById('YOUR_SHEET_ID'); const sheet = ss.getSheetByName(d.companyId + '-revenues'); sheet.appendRow([d.date, d.location, d.cash, d.card, d.total, d.fiscalNr, new Date()]); return ContentService.createTextOutput('{"status":"ok"}') .setMimeType(ContentService.MimeType.JSON); }
Testavimas (browser console):
window.importReceipt({"companyId":"darts","year":2026,"month":8,"date":"2026-08-11","location":"Vilnius","cash":200,"card":350,"total":550,"fiscalNr":"00011700"})

Pilnas Make.com scenarijo aprašymas: FB Messenger Webhook → Router (ar nuotrauka?) → Vision API / Claude API (OCR+parse) → HTTP POST į Apps Script → patvirtinimas atgal į Messenger.
